# GitHub settings checklist

Repository-level metadata is separate from the files in this pull request.

## Social preview

1. Open the repository on GitHub and choose **Settings**.
2. In **General → Social preview**, choose **Edit preview**.
3. Upload [`docs/assets/social-preview.png`](assets/social-preview.png) (the SVG source is also kept at [`docs/assets/social-preview.svg`](assets/social-preview.svg)).
4. Save the preview and verify it from an incognito link preview or a fresh chat.

The image is 1280×640, contains no third-party logos, and is designed to remain readable at thumbnail size.
